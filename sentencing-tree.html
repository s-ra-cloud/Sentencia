Sentencing Choice Tree

By Sacha Raoult

About This Tool

The Sentencing Choice Tree is an interactive machine learning tool designed for analyzing sentencing data. It allows researchers and legal professionals to upload CSV datasets and generate decision tree visualizations that reveal patterns in sentencing decisions.

This tool supports multiple machine learning frameworks and provides detailed performance metrics, making it valuable for both exploratory analysis and rigorous research.

📊

CSV Data Upload

Simply upload your sentencing data in CSV format and select your target variable.

🌳

Decision Tree Visualization

Generate clear, interpretable decision trees that show how variables influence outcomes.

🔧

Multiple ML Frameworks

Choose between scikit-learn, XGBoost, or LightGBM for tree generation.

📈

Performance Metrics

Get accuracy scores, confusion matrices, MAE, RMSE, and R² metrics.
