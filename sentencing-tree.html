Sentencing Choice Tree

Interactive ML tool · Decision trees · CSV analysis

Sacha Raoult

Launch

An interactive machine learning tool for analyzing sentencing data. Upload CSV datasets and generate decision tree visualizations that reveal patterns in sentencing decisions using scikit-learn, XGBoost, or LightGBM.

  • Upload sentencing data in CSV format and select target variables
  • Generate interpretable decision trees showing variable influence
  • Choose between scikit-learn, XGBoost, or LightGBM frameworks
  • Get accuracy scores, confusion matrices, MAE, RMSE, and R² metrics

Built with

Python FastAPI scikit-learn XGBoost LightGBM Pandas Matplotlib
